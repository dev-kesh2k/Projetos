# Projetos

Estudos de SAP (ABAP / SAPUI5).

## `zcopacol/`
App SAPUI5 *freestyle* gerado pelo `@sap/generator-fiori` (template simples, UI5 1.131, tema `sap_belize`), com uma lista de arquivos de exemplo (`webapp/model/items.json`, dados fictícios) e testes OPA/QUnit.

```bash
cd zcopacol
npm install
npm start          # servidor local do UI5 (ui5.yaml)
npm run start-local   # com ui5-local.yaml
```

Testes: abra `webapp/test/testsuite.qunit.html` pelo servidor local.
